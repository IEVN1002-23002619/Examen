# Proyecto Flask - Pizzería

## Configurar

1. Importa `../pizzeria.sql` en MySQL desde Laragon.
2. Revisa el usuario y la contraseña de MySQL en `src/config.py`.
3. Instala las dependencias con `pip install -r requirements.txt`.
4. Desde esta carpeta ejecuta `python src/app.py`.

La API queda disponible en `http://127.0.0.1:5000/api/pedidos/`.
